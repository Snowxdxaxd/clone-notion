# Тетрадь

Клон Notion для портфолио: блочный редактор с деревом вложенных страниц. Node 24, ESM, без сборки. SQLite (better-sqlite3), данные в `data/app.db`.

## Запуск

```
npm install
npm start          # порт 3014, можно переопределить: PORT=3000 npm start
```

Открыть http://localhost:3014. Вход по имени: новое имя автоматически создает аккаунт, при первом входе добавляются демо-страницы («Продукт» → «Идеи», «Встречи» → «Статус 19 ноября»).

## Возможности

- Дерево страниц в левом сайдбаре: раскрытие, кнопки «+» (подчиненная страница) и «⋯» (переименовать, публичная ссылка, удалить) при наведении.
- Drag&drop страниц: перетаскивание за заголовок, индикатор «выше / ниже / внутрь», перенос внутрь своего потомка запрещен.
- Блочный редактор: paragraph, h1, h2, h3, маркированный и нумерованный списки, чекбокс, цитата, код (с выбором языка), разделитель.
- Ручки блока при наведении: «+» — блок ниже, «⠿» — перетаскивание блоков с индикатором.
- Enter — новый блок ниже; в коде — перенос строки внутри блока. Backspace в начале пустого блока удаляет его, в начале непустого превращает в обычный текст. Стрелки вверх/вниз — переход между блоками с сохранением каретки.
- Слэш-меню: «/» в пустом блоке открывает список команд с фильтром по вводу, Enter или клик применяет тип.
- Markdown-шорткаты: `# `, `## `, `### `, `- `, `1. `, `[] `, `> `, `` ``` ``.
- Автосохранение: блоки и заголовок отправляются с задержкой, в шапке индикатор «Сохранение… / Сохранено».
- Публичная ссылка: «⋯» → «Копировать публичную ссылку», страница по адресу `/s/<токен>` открывается только для чтения, без сайдбара и ручек.
- Поиск по заголовкам и текстам блоков (иконка поиска в сайдбаре).

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/login` | вход по имени (сессия в cookie) |
| GET | `/api/me` | текущий пользователь |
| GET | `/api/pages` | список моих страниц |
| POST | `/api/pages` | создать страницу `{parent_id?, title?}` |
| PATCH | `/api/pages/:id` | переименовать/перенести `{title?, parent_id?, position?}` |
| DELETE | `/api/pages/:id` | удалить страницу вместе с потомками |
| GET | `/api/pages/:id` | страница + блоки |
| PUT | `/api/pages/:id/blocks` | заменить весь массив блоков |
| POST | `/api/pages/:id/share` | включить/получить публичный токен |
| DELETE | `/api/pages/:id/share` | отключить публичную ссылку |
| GET | `/api/public/:token` | страница по токену, без сессии |
| GET | `/s/:token` | тот же SPA, режим только для чтения |
| GET | `/api/search?q=` | поиск по заголовкам и блокам |

## Структура

```
server.js          — сервер и API
lib/               — каркас: http.mjs (роутер, статика), db.mjs (SQLite, миграции), auth.mjs (сессии), util.mjs
public/            — SPA: index.html, css/style.css, js/main.js
data/              — база SQLite (в .gitignore)
```

## Ограничения

- Вход по имени без пароля — демо-режим авторизации из каркаса.
- История версий, совместное редактирование и офлайн-режим не предусмотрены.
- Поиск — простой подстрочный, без морфологии и ранжирования.
- Публичная ссылка дает доступ к текущему содержимому страницы любому, у кого есть токен; отзывается через меню «⋯».
